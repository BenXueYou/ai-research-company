# T08 完整划拨与历史毛利交付记录

## 范围

卖方在直属订单已确认收款并预留后，可从订单页面发起一次完整划拨。服务端核验会话、卖方权限、直属且启用的买方和订单状态，在一个 PostgreSQL 事务内减少卖方余额及预留、增加买方余额、记录只增划拨账。分销买入按原余额成本与本次买价计算四位小数移动加权平均成本；划拨账保存卖方单位成本、销售成本、金额和毛利快照。已收款数量及售价保持锁定。未收款报价继续沿 T07 的当前成本和最低加价率重验。
