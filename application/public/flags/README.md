# Country selector assets

Local SVG flags copied from [flag-icons v7.3.2](https://github.com/lipis/flag-icons/tree/v7.3.2/flags/4x3), under the MIT license in `LICENSE`.

Country alpha-2/alpha-3 codes and English names in `web/pages/companies/countries.ts` are derived from [mledoze/countries](https://github.com/mledoze/countries/blob/master/countries.json), retrieved 2026-10-29, under ODbL (`COUNTRY-DATA-LICENSE`). Chinese display names were generated with Node's `Intl.DisplayNames('zh-CN')`. This display directory does not define supplier coverage or change the API's accepted country code format.
