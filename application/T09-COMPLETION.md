# T09 已收款未划拨订单线下整单退款交付记录

## 范围与契约

仅直属卖方管理员可对 `reserved` 订单确认已完成的线下整单退款。请求使用页面所点订单的 `order.id` 作为 `orderId`，并提交本次填写的退款依据；服务端以该订单锁定的 `amount` 记录整单退款金额，不从页面金额重新取值。退款事务将订单关闭为 `refunded`、释放该单全部销售预留，并写入只增记录，含金额、依据、操作人、时间和释放后预留。余额和买方点数不变。已划拨、未收款、已退款及非卖方订单拒绝新退款请求。同一请求标识重放返回原结果，不能重复释放。

按 2026-10-27 更新的 R44，库存不足收款登记形成的待补库存履约分支不退款；目前该收款登记分支尚未实现，因此本次退款仅允许现有的 `reserved` 状态。组织停用仍遵循既有卖方鉴权，不因退款扩大跨级或停用期间操作权限。
