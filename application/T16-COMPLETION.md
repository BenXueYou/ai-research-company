# T16 共享档案补充、状态筛选及软删除恢复

日期：2026-10-27。本地实施，未提交、推送、部署或修改线上工单。追溯：Spec US-19、59～60、63；PRD R33～35、R60～61；AT-06、AT-18 中的档案范围。

## 实现

- `company_profiles` 保留原档案 UUID、`detail_id`、`query_id`、源详情和获取时间，新增主营产品、采购需求、合作意向、下次跟进时间、四态客户状态、星级、标签及软删除标记。所有新增人工写入记录操作人、时间、修改前后值。未新增自定义字段或自动跟进提醒。
- 本终端企业管理员与业务员共享查看、编辑。档案库按四态和北京时间跟进日期筛选。状态仅由人工编辑入口调整；邮件发送状态不参与此更新。企业管理员可软删除与恢复，重复操作幂等；业务员、其他企业、平台身份均无此权。软删除后从普通档案库、联系人、时间线、附件和重新报价入口隐藏；管理员从已删除筛选恢复。
- 档案行不物理删除，已有 T15 查询历史、T17 人工记录、T18 附件及 T21～T24 邮件预览/批次的档案外键保持原值。删除及恢复不修改它们，也不触碰 T25 额度状态。
