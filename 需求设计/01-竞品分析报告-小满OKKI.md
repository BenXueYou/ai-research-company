## 一、竞品定位与产品矩阵

**【公开】** 小满科技成立于 2013 年，2020 年被阿里巴巴全资收购，现为阿里巴巴国际站旗下外贸 AI 品牌。官方口径：13 年深耕外贸、25 万+ 外贸人使用、B2B SaaS 市占率第一（艾瑞咨询数据）。

产品矩阵分三条线：

| 产品线 | 定位 | 覆盖环节 |
|---|---|---|
| **OKKI Leads / AiReach** | 营销获客智能体 | 目标客户发现 → 客户背调 → 触达准备 |
| **OKKI CRM** | 客户经营与销售管理 | 客户资料、联系人、跟进记录、商机、订单 |
| **OKKI Shops** | 外贸独立站 | 建站、SEO、询盘承接 |

**【公开】** 2025 年 6 月，OKKI 宣布完成从「AI 工具」到「AI 智能体」的跃迁，AiReach 主打「AI 主动找客户」。

**【推断】** 竞品已从「数据库查询工具」演进为「Agent 驱动的主动获客」。我方产品若只做数据检索 + 群发，会落后一个代际；`智能化 Agent` 模块不是加分项而是必选项。

## 三、获客链路逐模块拆解

### 3.1 智能获客（主入口）

**【公开】** 官方话术：「一个窗口完成潜客搜索-筛选-背调，获客更高效」。

页面构成（据第三方截图 OCR）：

| 区域 | 内容 |
|---|---|
| 数据量展示 | 「153,850,217 企业记录」「707,691,905 联系人记录」——用绝对量级建立信任 |
| 搜索入口 | 双 Tab：**找公司** / **找联系人** |
| 搜索条件 | 「目标客户在哪里？」（国家/地区）＋「您营销产品或公司名称是什么？」（关键词） |
| 客户推荐 | 「根据您填写的信息，为您推荐相匹配的公司」＋ **推荐偏好** 可配置 |
| 推荐卡片 | 公司名、国家、关键词、公司简介摘要、数据来源标注 |
| 运营位 | 「近期累计引入 300w+ 条俄罗斯和 300w+ 条东盟潜客数据，快来搜热门外贸市场潜客」 |

**【公开】** 数据规模（2026 年 4 月扩容后）：新增 1.07 亿潜客公司、1.13 亿核心决策人、6.2 亿+ 进出口贸易单据；累计口径宣传为全球 12 亿+ 联系人，覆盖 95% 外贸重点市场。

**【推断】关键设计洞察**：
1. **首屏直接展示数据总量**，这是数据类获客产品最有效的信任构建手段。我方首页的地球视觉承担同一职责，但必须补一个「已入库企业数 / 联系人数」的实时计数器，否则视觉再炫也不传达可信度。
2. **「找公司 / 找联系人」双入口分离**，对应两种完全不同的用户心智：找公司=市场开拓，找联系人=直接触达。我方 spec 里「智能获客」和「关键人挖掘」是两个菜单，思路一致，但建议在搜索首页就提供切换，减少跳转。
3. **推荐偏好可配置**——说明竞品把「推荐」做成了一等公民，而非搜索的附属。

### 3.2 海关数据 / 贸易记录

**【公开】** 能力要点：
- 支持按公司名或产品搜索，查看目标公司出口流向及关联客户
- **智能贸易数据识别**：找出「高频采购但当前供应商少」的客户
- 把握采购周期，挖掘无贸易数据或低曝光的中小买家
- 查询特定公司出口记录及对应买家信息

**【公开】** 竞品自身的海关数据被第三方评测指出局限：「数据深度依赖阿里国际站生态，非阿里生态客户覆盖偏弱」。另有行业对比文章将腾道数据列为覆盖度领先者（100 亿+ 贸易数据、228 个国家地区、20 亿+ 交易明细、172 国商业数据）。

**【推断】这是我方最重要的差异化机会**：我方直接对接腾道开放 API，数据覆盖度与字段完整度（含发票币种、CIF/FOB/CFR/EXW 贸易术语、集装箱号、提单号等专有字段）可能优于竞品。但要注意——**腾道的数据是按点数计费的，竞品的数据是打包在年费里的**。这决定了我方必须在产品层做「点数消耗可视化 + 查询前置预估」，否则用户会因为怕烧点数而不敢用，这是竞品没有的成本焦虑，也是我方必须解决的体验问题。

### 3.3 客户背调 / AI 画像

**【公开】** 竞品 AI 背调能力：
- 系统自动抓取公司官网、社媒动态、进出口趋势、产品词云
- 生成 **推荐指数**
- 整合企业信息、关键决策人联系方式及进出口动态
- 宣称「背调效率提升 10 倍」「以前背调要开 5 个网页查半天，现在一个界面客户底牌全看清」

**【公开】** AI 画像的评估维度（据产品页 OCR）：

| 维度 | 具体内容 |
|---|---|
| 行业匹配关系 | 「买家为医疗设备分销商，卖家为医疗设备制造商，产业链上下游关系明确，行业高度相关」 |
| 采购需求分析 | 「买家主营医疗设备，有采购需求」 |
| 供需匹配 | 「官网简介/SEO 包含关键词 xxx」 |
| 社媒活跃度 | 「近一周内在 #社媒名称# 发布 N 个跟 xxx 相关的帖子」 |
| 联系人规模 | 「9 名联系人」 |
| 挖掘渠道 | 「进出口贸易数据」 |
| 市场机会 | 「买家市场机会·北美地区」 |
| 动态挖掘策略 | 图谱分支、高优推荐、已打开等状态标签 |

**【公开】** 潜客漏斗看板字段：`全网匹配数据 10,520`（距昨日 ↑80）→ `已挖掘潜客 2,187`（距昨日 ↑50）→ `触达中 356`（距昨日 ↑20）。潜客列表字段：主营产品、公司类型（如「医疗设备分销商」）、跨国采购、OEM/ODM、已打开、高优推荐、潜客评估。

**【推断】这是竞品最成熟、也最值得对标的模块。** 关键不是「有画像」，而是画像的**可解释性**：竞品把每条判断都写成自然语言理由（「产业链上下游关系明确」），而不是只给一个分数。我方 `AI 分析` 模块必须做到同等程度的归因输出——一个无法解释的推荐指数，业务员是不敢用来决策的。

漏斗看板的「距昨日 ↑N」也值得抄：它把静态数据变成了趋势信号，制造每日回访动机。

### 3.4 地图获客（我方 spec 未覆盖）

**【公开】** 路径：`OKKI Leads` → `渠道获客` → `地图获客`。

- 数据源为谷歌地图数据
- 页面三部分：搜索区域、搜索结果列表、地图上的区域搜索
- 搜索条件：产品关键词、公司名称、国家/地区、城市
- 结果列表展示：公司名称、地址、域名等
- 核心价值：「对于集群效应明显的产品/行业，找到一个潜在客户后，可以通过地图功能快速挖掘查找附近更多的潜在客户」
- **限制**：需要使用合法跨境专线才可查看地图并搜索

**【推断】** 这是一个「以点带面」的巧思——利用产业地理聚集性做客户扩展，数据成本低（谷歌地图）但场景价值高。我方视觉稿的中心就是 3D 地球，天然适合承载地图获客，建议纳入 P2 迭代（详见 PRD）。腾道 API 不提供 POI 数据，需另接地图数据源，且跨境专线是硬性依赖，落地成本需评估。

### 3.5 多渠道触达

**【公开】** 竞品触达渠道：WhatsApp、阿里卖家（TM 消息）、Facebook、邮件、EDM、LinkedIn。

**邮件能力细节**（对我方 `邮件营销` + `送达检测` 最有参考价值）：

| 能力 | 说明 |
|---|---|
| 多邮箱绑定 | 单账号最多绑定 **10 个**邮箱，支持**轮流发送** |
| 协议要求 | 需开启 IMAP/POP3 和 SMTP；小众邮箱手动配置，IMAP 端口 993/SSL，SMTP 端口 465/SSL |
| 群发单显 | 支持（每个收件人只看到自己的地址） |
| 邮件追踪 | 实时监测邮件**打开的次数、时间和地点**，「快速锁定商机」 |
| 邮件健康测评 | 官方话术「群发无忧」，提供邮件健康度检测 |
| 模板 | 内置精美邮件模板、快速选择联系人 |
| 多维度管理 | 同一账户绑定多邮箱，通过文件夹、标签、客户三个维度全局管理 |
| AI 辅助 | 智能邮件润色、多语言开发信生成；宣称海外客户邮件回复率提升 32.12%、邮件回复率可达 15% |

**自动化营销计划**：**【公开】** 支持根据客户查看状态自动迭代营销内容，针对**未读、已读**等不同状态执行差异化多轮触达；**沉睡客户激活**——系统自动识别长期未联系客户，支持批量加入营销计划自动化召回。

**【推断】「送达检测」是我方 spec 里定义最模糊、但竞品做得最实的一环。** 竞品没有独立的「送达检测」菜单，而是把它融进了邮件追踪（打开次数/时间/地点）和邮件健康测评。我方把它单列为菜单，反而是一个**清晰的差异化卖点**——外贸邮件最大的痛点就是进垃圾箱和硬退信，一个能明确告诉用户「这个邮箱能不能收信、你的域名信誉如何」的独立工具，价值感比模糊的「追踪」强得多。建议在 PRD 中把它做实：邮箱有效性验证（SMTP 探测）、退信分类、域名/IP 信誉监测、预热策略。

**WhatsApp 注意点**：**【推断】** 我方 spec 写的是「whatApp公开人联系」（应为 WhatsApp 公开联系人）。竞品是「打通 WhatsApp 沟通」，而我方定位是「**公开**联系人挖掘」——即从公开数据中提取 WhatsApp 号码用于主动添加。这两者合规风险差异巨大：主动添加陌生人 WhatsApp 号码涉及 GDPR、以及 WhatsApp 官方的反垃圾政策，封号风险真实存在。必须在 PRD 中明确合规边界与风险提示，这一条不能含糊。

### 3.6 线索管理

**【公开】** 
- 多渠道客户统一建档：线上 B2B 平台（阿里国际站、环球资源）、独立站、Facebook/Ins 等社媒、线下展会、企业自开发
- 搜索到的线索可转化为正式客户，提供**批量转化**并**自动过滤无效线索**
- 重复线索可选择合并
- **智能线索清洗**：自动过滤失效信息，一键定位关键决策人（邮箱/WhatsApp/领英）
- 客户分类维度：客户状态、客户分组、公海分组、星级
- 客户公海 + 自动分配

**【推断】** 「公海/私海」是 CRM 的存量运营机制，我方若不做成交后管理，可以简化为「公共线索池 + 认领/分配」，保留防止撞单的核心价值即可，不必照搬全套公私海流转规则。

## 四、商业化与成本结构

**【公开】**

| 项目 | 竞品口径 |
|---|---|
| 定价 | 19,800 元/年起，含 5 用户，按席位加购 |
| 免费版 | 无永久免费版 |
| AI 尊享版 | 19,990 元/年起（第三方评测口径，可能为不同产品线） |

**【推断】定价策略启示**：竞品把海关数据做成模糊权益（需问销售），这是典型的销售驱动打法。我方对接腾道是**按点数实付成本**，反而可以做成透明的「点数制/查询量套餐」，把成本焦虑转化为可预期的消耗看板——这是中小客户更喜欢的方式，也是对竞品的正面差异点。

## 五、竞品优势与我方机会点

### 5.1 竞品护城河（不宜正面进攻）

| 优势 | 说明 |
|---|---|
| 数据规模 | 12 亿+ 联系人、6.2 亿+ 贸易单据，且持续扩容，自建成本极高 |
| 全链路闭环 | 获客 → CRM → 独立站 → 经营分析，数据在一个体系内流转 |
| 阿里生态 | 国际站询盘数据打通，这是纯第三方拿不到的 |
| AI 成熟度 | 已完成 Agent 化，背调、润色、推荐、谈单监测、沟通质检齐备 |
| 品牌与存量 | 13 年、25 万用户、市占率第一 |

### 5.2 我方机会点

| 机会点 | 依据 | 优先级 |
|---|---|---|
| **数据字段深度** | 直连腾道，可拿到发票币种、贸易术语、集装箱号、提单号等竞品未必暴露的字段；腾道覆盖 228 国、172 国商业数据 | P0 |
| **成本透明化** | 竞品海关数据权益模糊需问销售；我方可做点数消耗实时看板 + 查询前预估 | P0 |
| **送达检测独立成模块** | 竞品融在邮件追踪里，价值感弱；我方单列可做成明确卖点 | P1 |
| **WhatsApp 沟通留档** | 竞品的 WhatsApp 会话存档依赖平台官方授权（第三方拿不到），业务员实际在手机上聊、CRM 里无留档，存在断档。我方用「手动登记 + 聊天截图上传」这条不依赖平台授权、也无主动触达合规风险的路径补齐（PRD C-11～C-16） | P1 |
| **轻量、聚焦、快** | 竞品是重型全链路平台，学习成本高；我方只做获客链路，上手快、部署轻 | P0 |
| **画像可解释性** | 竞品已做到自然语言归因，我方必须对齐，不可只给分数 | P1 |

### 5.3 我方明确不做（边界）
