# V2 浅色工作台原型

## 2026-10-26 开户与密码管理同步（v3.1）

当前可交互原型为 `原型V2.html`，A/B/C三套布局共用本轮新增账号流程，依据PRD R70～R77及技术设计。下文原布局探索记录保留为历史背景；其中“业务脚本原文不变”的说明仅适用于此前布局探索，本轮按已确认需求调整了账号流程。`prototype-smart-acquisition.html` 为历史视觉参考稿，本轮未修改。

- 开户：切换为平台或分销角色，进入“下级管理 → 开户（直属下级）”，填写组织信息、必填电话号码和管理员邮箱。邮箱全平台唯一，系统生成随机临时密码；成功页“一键复制账号信息”同时复制邮箱和临时密码。复制失败可重试或手动复制，不重新开户。
- 交付后关闭成功页不再展示该密码；在“下级详情 → 重置管理员密码”确认重新生成后，旧密码立即不能再登录，新凭据可一键复制。
- 创建成员：企业管理员填写姓名、登录邮箱、角色，系统生成临时密码，取代原手填初始密码。成员重置也采用系统生成方式；停用保留成员记录及既有业务历史，重置不恢复停用状态。
- 登录与改密：右上角提供“账号设置”和“退出登录”。账号设置内修改密码须验证当前密码、新密码与确认新密码，成功后重新登录。首次及重置后登录进入专用改密页，完成前不能进入业务页面。
- 忘记密码：登录页说明企业成员找本企业管理员，组织管理员找直属上级，平台管理员联系指定运维核验身份后通过维护工具恢复、留痕并下次改密。原型不提供真实运维维护工具。

体验新账号：开户或成员创建成功后，先复制凭据，再点击“演示此账号登录”，用临时密码登录并改密。新账号使用独立的账号演示页，不加载原演示企业档案；完整的新企业业务工作台不在本轮账号流程演示中。上方角色选择器是演示辅助，可返回原业务演示；强制改密期间禁用该选择器。

演示环境：页面初始进入终端管理员工作台；已有演示邮箱为 `admin@example.test`、`wang@example.test`、`distributor@example.test`、`platform@example.test`，初始演示密码为 `Demo@2026`。全部账号仅保存在本页内存，刷新后恢复初始演示数据。仅使用虚构测试信息。

验证：A/B/C各通过13项新增账号检查，共39项；既有业务回归每套22项，共66项，覆盖不同标识值、联系人选择至邮件提交及点数交易。原手填密码测试由新增账号测试替代。报告见 `archive/tmp/account-verification.json`、`archive/tmp/account-business-A-verification.json`、`archive/tmp/account-business-B-verification.json`、`archive/tmp/account-business-C-verification.json`。新增流程截图为 `archive/tmp/account-opening-desktop.png`、`archive/tmp/account-opening-mobile.png`、`archive/tmp/account-login-mobile.png`。

限制：这是前端内存交互演示；密码仅使用带随机盐的摘要作演示校验，不是生产密码存储方案。复制失败和成功反馈已通过浏览器剪贴板替身验证，真实系统剪贴板及权限环境尚未实机验证。未验证真实数据库唯一性和事务、后端鉴权、跨设备会话、生产审计或运维恢复工具；密码强度、临时密码有效期、邮箱等价及电话格式等未决规则沿用PRD，不新增默认约束。

## 既有布局探索记录

本轮问题：参考 `prototype-smart-acquisition.html` 的蓝紫侧栏、浅色背景、白色卡片及市场探索区，能否承载 V2 已有全部功能模块？此文件为一次性设计探索，尚未选定最终方案。

打开方式：在项目根目录运行 `Start-Process '.\原型设计\原型V2.html'`，或直接双击 HTML。全部资源内嵌，无需安装或联网。

底部箭头或键盘左右键切换；输入框中不拦截方向键。URL 中 `?variant=A`、`?variant=B`、`?variant=C` 可固定布局。

- A：地图探索区在左，筛选在右，最接近参考页。
- B：横向搜索优先，市场示意在下方，便于连续查询。
- C：左侧紧凑筛选；档案页并排呈现列表与详情。

三套布局共用原有内存演示状态。底部“演示状态”可查看当前角色、选择、请求和提交快照。角色切换可检查企业、业务员、分销及平台全部既有模块。

本轮保留 V2 第一段业务脚本原文，仅通过样式、外壳及展示装饰调整页面；原参考 HTML 未修改。没有新增真实请求或持久化，没有变更标识映射、枚举、默认值、校验及提交条件。
