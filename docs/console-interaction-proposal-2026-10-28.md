# 公共控制台新版交互方案

日期：2026-10-28（Asia/Shanghai）  
适用范围：平台、分销、终端四类角色的公共控制台框架，以及后续接入框架的业务页面。  
关联票据：[公共控制台与四角色 History 导航 #34](https://github.com/BenXueYou/ai-research-company/issues/34)

## 1. 方案目标

用户进入任一业务页后，只需要回答三个问题：我现在在哪个业务层级、我应该在哪里操作、页面还能向下滚动到哪里。公共框架负责位置和导航，业务页面负责内容与业务动作；两者在视觉和滚动行为上明确分开。

这次方案保留现有路由、角色权限、请求字段、校验和提交条件，只调整公共布局、页面级标题层级和交互反馈。

## 2. 页面骨架

采用 Element Plus Container 组合，形成“固定框架 + 两个滚动区”的结构：

```text
┌───────────────┬──────────────────────────────────────────────┐
│ 品牌          │ el-header  面包屑             账号  设置  退出 │  ← 固定
│ el-aside      ├──────────────────────────────────────────────┤
│               │ el-main                                     │
│               │                                              │
│               │ 业务内容                                     │
│ 角色菜单      │ 卡片 / 表单 / 列表 / 详情                     │  ← 独立滚动
│               │                                              │
│ 侧栏滚动      │ 内容滚动                                     │
└───────────────┴──────────────────────────────────────────────┘
```

- `el-container`：占满浏览器视口高度，禁止外层产生纵向滚动。
- `el-header`：右侧内容列的固定顶部，包含 `el-breadcrumb` 和账号操作。
- `el-aside`：固定宽度或窄屏可折叠，菜单在自身区域滚动。
- `el-main`：只承载业务页面滚动；业务页内部的表格横向滚动限制在表格容器内。
- 所有涉及高度的 Container 子项设置 `min-height: 0`，避免 Flex 子项把滚动传递到整个页面。

## 3. 顶部面包屑

### 展示规则

面包屑表达“业务域 / 页面 / 当前对象”三级关系，来源于当前已授权路由的导航元数据，不从 URL 字符串猜测名称。

| 场景 | 示例 | 可点击项 |
| --- | --- | --- |
| 一级页面 | `运营概览` | 无 |
| 列表页 | `下级管理 / 直属下级` | `下级管理` |
| 详情页 | `下级管理 / 直属下级 / 星河科技` | 前两级 |
| 配置页 | `平台设置 / 计价配置` | `平台设置` |
| 账号页 | `账号设置` | 无 |
| 帮助页 | `帮助中心` | 无 |

表中的父级只有存在已授权且有效的页面入口时才可点击；纯菜单分组只展示文字。当前页面只显示一个末级名称，不再在业务内容区重复放置同名的大号页面标题。详情对象名称、表单分组标题、费用与风险提示仍然保留。

### 点击行为

1. 点击父级面包屑先执行现有离开保护。
2. 没有未提交内容时立即进入父级路由，并将内容滚动位置重置到顶部。
3. 有未提交内容时弹出“继续编辑 / 放弃修改并离开”；取消保持原输入和滚动位置。
4. 已提交但结果未确认时沿用业务模块的核对策略，不由公共布局取消、重试或假定成功。
5. 无权或不存在的路径不显示为可点击面包屑；直接访问仍由前端守卫和服务端权限共同拒绝。

## 4. 菜单与业务区交互

### 菜单

- 当前路由只高亮对应的叶子菜单；详情页高亮其所属列表入口。有子菜单的父级只反馈展开状态，不与当前子项同时选中。选中样式统一使用浅色背景与白色文字，不加左侧白色竖线或边框；键盘焦点仍保留清晰的焦点提示。
- 顶部左侧提供“收起菜单 / 展开菜单”按钮，点击切换侧栏显示，业务区域随之扩展或恢复。收起与展开不切换路由，不丢失输入，也不重置业务区滚动位置。
- “点数与账务”“上游与对账”“平台设置”等有子项的菜单可点击展开、收缩，右侧箭头同步变化；点击分组只改变子项可见性，不跳转业务页面。多个分组可独立展开；通过快捷入口或面包屑进入子页时自动展开对应分组。
- 删除侧栏底部“平台运营工作台”说明栏，将空间留给菜单；保留各角色原有帮助入口。
- 菜单滚动只改变 `el-aside` 内部位置；点击菜单后业务区滚动到顶部。
- 左侧菜单与右侧业务区统一采用不透明蓝灰色滑块：浅色模式 `#a6afd6`，悬停或区域内键盘聚焦时为 `#8794c0`；深色模式分别为 `#8492bd`、`#a6afd6`。两侧复用同一组颜色，避免半透明色叠加不同底色产生视觉色差；轨道均透明、滑块圆角且宽度一致（标准细滚动条，WebKit 回退为 6px），系统强制色彩模式下遵循系统设置。
- 菜单项文字采用用户业务语言，不展示组件名、路由名或迁移状态。
- 平台帮助中心保留在主菜单，分销与终端帮助入口保留在侧栏底部；账号设置从顶部账号区进入，已有深链入口保持可用。

### 业务区

- `el-main` 是唯一业务纵向滚动容器，卡片、表单和列表按业务顺序自然向下排列。
- 页面底部不放悬浮遮挡层；固定操作栏只在表单确有需要时使用，并预留内容底部空间。
- 长表格使用局部横向滚动，不能撑宽 `el-main` 或触发浏览器横向滚动。
- 进入业务页不自动刷新上游状态、不自动重放收费查询、邮件、订单等业务请求。

## 5. 页面内容层级

采用“面包屑定位，卡片标题组织内容”的层级：

```text
面包屑：点数与账务 / 平台采购

卡片：采购入账
  说明文字
  表单字段

卡片：平台承担费用
  费用用途、金额、核对依据

计价配置通过“平台设置 / 计价配置”进入，保留配置字段与风险提示，不与采购表单混放。
```

不再出现与面包屑末级完全相同的页面大标题。卡片标题必须说明用户正在查看或填写的业务对象；错误、空状态、费用和风险说明留在相关卡片附近。

## 6. 响应式与可访问性

- 桌面宽度：侧栏展开，顶部面包屑与账号区同一行。
- 窄屏：侧栏折叠为抽屉或可展开区域；打开菜单后保留当前项，选择后自动收起并回到业务区。
- 面包屑过长时，中间层级使用省略号，末级当前页保留完整；悬停或键盘聚焦时提供完整名称。
- 所有菜单、面包屑和账号操作支持键盘聚焦；焦点样式清晰，抽屉打开时焦点不跑到遮罩后。
- 尊重 `prefers-reduced-motion`，滚动定位和抽屉切换不依赖动画完成。

## 7. 关键流程

### 进入详情并返回

1. 用户点击“下级管理”。
2. `el-main` 显示列表，面包屑为“下级管理 / 直属下级”。
3. 用户点击某组织进入详情，面包屑增加组织名称。
4. 点击“直属下级”返回列表，保留现有筛选和业务上下文；同会话前进后退恢复各历史位置对应的内容滚动位置。跨业务菜单主动导航从顶部开始，侧栏滚动位置独立保留。不新增隐式提交。

### 编辑表单后切换

1. 用户修改采购或配置字段。
2. 点击菜单、面包屑、返回或浏览器后退。
3. 公共离开保护弹出选择。
4. “继续编辑”关闭提示并保留输入；“放弃修改并离开”才切换路由。

### 菜单与内容分别滚动

1. 菜单项超过视口高度时，只滚动左侧菜单。
2. 长业务页面滚动时，左侧菜单位置不变。
3. 继续滚动到业务底部，最后一个字段、提示和操作按钮均可见且可操作。
