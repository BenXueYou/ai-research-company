# T13 未决查询人工核对、退款及迟到结果处理

## 已实现

- 平台核对页列出企业详情、联系人页及产品名单页的结果确认中查询，同时可回看已处理查询、账单引用、traceId、可查看结果证据、处理依据、操作人、时间和迟到结果。平台可依据实际账单与结果证据确认成功、真实零结果或最终失败；仅处理原查询冻结，不改变其报价系数、上限和请求参数来源。未设置自动核对期限。
- 详情结果按原候选国家、供应商 `data.id` 验证；联系人页按原页码、页大小及原始 `mailsouId`、返回公司名入档；产品名单页按原页码、页大小和名称候选入档。成功按原锁定 X 和上限结算，失败及零结果释放冻结。重复核对相同证据返回原处理结果，冲突证据拒绝；账单与供应商回执乱序时查询行锁保护一次结算。
- 最终失败后的迟到结果单独留存；原查询保持失败及退款状态，余额不重新扣除。已知的失败上游扣点和超额上游点数单列为查询损耗；平台费用可关联该损耗查询，再关联补充值。同一查询损耗最多关联一笔费用；补充值保留资金支出和上游点数，但不增加销售库存或移动加权成本。
- 生产腾道详情和联系人响应的 traceId 进入核对证据。上游响应未证明实际扣点时继续保留冻结等待账单，不以报价代替实际费用。
