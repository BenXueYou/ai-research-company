## 生命周期

- 页面实例限定 KeepAlive，按会话 generation 销毁；返回、前进后退和同组件 query 切换不自动重新读取列表或执行写请求。首次进入与手动刷新沿用原 GET。刷新重新读会话和列表，不恢复草稿、凭据或未知请求。
- 接入公共 useFormLeave：有输入、类型/区号修改或待交付凭据时可继续编辑或确认放弃；提交中拒绝离开；放弃清除表单与凭据。同组件 query 更新同样受保护。成功关闭凭据后保留旧组件原有类型/区号选择，以该值建立干净基线，避免将已完成开户误判为未提交草稿，不改变下次请求取值。
- 开户丢失响应保留原输入及 requestId、冻结字段；切页返回不自动重放。用户主动重试仍使用原请求，已落库返回409；明确核实结束才生成下一请求标识。重置丢失响应锁定再次重置，明确核实补发后才允许新的主动请求。
- 状态调整丢失响应后锁定状态按钮，手动刷新真实直属列表后再允许操作；不会凭旧状态自动取反重发。未知状态可确认离开，返回保留核实提示。
- 临时凭据只在当前页面内存当次交付，复制失败只重试剪贴板；关闭、放弃、刷新和会话销毁不恢复密码。没有新增密码回放、短信、邮件交付或存储持久化。
