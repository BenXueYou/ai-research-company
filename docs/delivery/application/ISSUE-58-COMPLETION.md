# Issue #58 成员管理独立页面

2026-10-28。本地实现及独立真实环境验证完成，未部署、重启既有服务、提交、推送或关闭工单。实施前通过 GitHub REST 读取实时 #58（Open，无评论），核对控制台迁移 Spec v1.2、工程脚手架、应用 README、T03/T04 当前服务及成员页面。Open 状态未作为缺失实现的依据。

## 基线及职责

原 `MemberManagement.vue` 位于 `web/pages/organizations`，由 CompatWorkspace 仅对 admin 挂载；路由为 EmptyRoute，以 `compat-members` 滚动定位。服务已实现成员创建、当次密码交付、重置、停用与权限。本票保留这些服务，不新增业务权限。

现在 `/terminal/members` 直接渲染该页面，移除原兼容挂载、导入及本票 target；请求适配位于 `web/api/members.ts`。页面没有需拆出的单独子组件。业务员可进入六入口之一，但只显示权限说明，不读取成员名单；GET/POST 仍由原服务拒绝。

页面限定 KeepAlive 缓存，以 App 现有 session generation 销毁。离开保护使用公共 useFormLeave：输入或未保存凭据可取消离开保留、确认放弃清除；提交中阻止路由离开；结果未知可确认离开，保留原操作和载荷，返回不自动读取或重发。主动“核实原请求”使用原 requestId，服务端已执行则返回 409，不重复生成或回显密码。凭据关闭后清除；浏览器刷新不持久化凭据或未知上下文。刷新/关闭浏览器使用公共 beforeunload 提醒，不能视为跨刷新恢复。

## 修改前后契约

| 操作 | 原来源及最终请求 | 迁移后 | 服务端和结果 |
| --- | --- | --- | --- |
| 列表 | GET members，无客户端组织字段 | 相同，仅 admin 发起 | 会话账号所属组织；sales 403 |
| 创建 | 表单原样 name/email/role，默认 sales；当前 UUID requestId | 相同，未知时保存完整原载荷 | actor.organization_id；不接收客户端组织、密码；仅邮箱域名转小写；24 字符临时密码、72 小时且强制改密 |
| 重置 | 所选 member.id → accountId，点击生成 UUID requestId | 相同，未知核实沿用原 UUID | 当前管理员授权目标；撤销目标旧会话；重复 409 不回显 |
| 停用 | 所选 member.id → accountId | 相同 | 本企业授权成员；本人和首位管理员拒绝；停用并删除会话 |

真实夹具将平台账号/组织、企业甲账号/组织、企业乙账号/组织、成员账号设为不同 UUID。创建输入 `Member+58@EXAMPLE.COM`，落库 `Member+58@example.com`，role=sales；重置与停用均断言最终 accountId 等于该成员账号 ID，且不同于组织 ID。原请求及实际 UUID 留存在 [机器证据](ISSUE-58-EVIDENCE.json)，不保存密码、连接串或密钥。

## 实际验证

在 application 执行 `node scripts/verify-issue58.mjs`：通过，Playwright 1 passed（23.9s）。脚本创建随机独立 PostgreSQL 17.6 容器、随机名称 `_test` 库和映射端口，完成后删除自身容器。Nest/Vite 测试服务为本票新建进程内实例，停止时不触及已有服务。服务端产物、前端构建和浏览器结果位于 `.scratch/issue58`，没有写共用 dist 或 test-results。

- 真实浏览器操作管理员创建 sales/admin，双击只发一次；姓名/邮箱/角色/requestId 来源、字段白名单及真实落库一致。
- 复制失败后保留当次凭据，可再次复制；密码 24 字符、有效期 72 小时、首次强制改密，改密前接口拒绝；关闭/刷新后不显示凭据。
- 真实浏览器登录成员、完成强改密；管理员重置后旧会话 401；重置重复 409；停用后 active=false。
- 本人重置/停用 403；第二管理员不能停用首位管理员；跨组织重置/停用 403；非法角色和非法邮箱 400；重复创建 409；业务员页面无维护入口，GET/创建/重置/停用直接 HTTP 均 403。
- 表单离开取消保留、放弃清除；后退/前进；提交中账号设置导航被阻止；实际请求在后端成功后丢弃响应，创建及重置保留未知上下文，切页返回不发额外请求；主动核实发送完全相同原载荷，数据库各幂等记录仅一次。
- 构建版直达和刷新；Vite 登录后直达/刷新；未知 API 不返回 HTML，构建版缺失资源 404；平台/分销不能访问本页或成员 API；管理员切换到其他企业不残留名单或凭据。

构建首次因本票测试引用 Identity 的 organizationId 而失败，已按真实字段 organization_id 修正。一次全服务端编译遇到并行 #52 测试 TS2774；本票使用专用 tsconfig 限定服务及 #58 测试，未修改他票代码。未知结果测试先前在提交结束前取计数，已改为等待可核实状态。Vite 原先复用其他端口同域 cookie 导致预期登录页不成立，已使用独立浏览器 context 和精确 origin 完成真实登录验证。上述失败不记作通过。
