# T04 按管理关系重置及补发临时密码

日期：2026-10-27。基线：本地 Spec v1.2、PRD R71/R76、US-04/11/12/13、AT-02/03/04 中由 T04 承担的重置部分。现有共享工作区含 T03/T06/T10/T19 等未提交改动；本票在其上增量实现，未回退或提交其他票。

## 交付

- `POST /api/password-resets` 仅收 `accountId`、`requestId`。当前终端企业管理员可重置本企业其他成员；平台或分销管理员仅可重置直属下级组织开户记录对应的首位管理员。接口在事务内锁定操作者与目标账号、重新校验会话及组织关系。
- 密码学随机临时密码以加盐摘要保存，成功后撤销目标所有会话，设置强制改密及沿用既有 72 小时临时有效期。重复 `requestId` 拒绝再次生成或回显；并发不同请求串行，只有最后提交的凭据可认证。账号启用状态、邮箱、角色、组织、姓名及账务不变。
- 成员列表与直属下级详情可执行重置。成功页只在当前视图内显示并复制邮箱和新密码；关闭、退出、刷新后不再从服务端查询凭据。审计保留操作人、存在于数据库的目标账号、时间、结果，不存明文、摘要或会话令牌；无效或不存在的目标仅记录操作人与拒绝结果。

## 业务与参数证据

- 浏览器选择成员行 `T04.Member.UI+tag@example.com` 后，请求 `accountId` 等于该行真实成员账号 ID，且与组织 ID 不同；选择直属下级详情后，请求等于该行 `accountId`，不取 `id`（组织 ID）。两个选择均核对返回邮箱及真实剪贴板内容，关闭后页面密码消失。
- HTTP/PostgreSQL 场景使用互不相同的平台、分销、终端组织、开户账号、管理员、业务员 ID 和邮箱、电话。覆盖本企业业务员/管理员、直属下级管理员成功；跨企业、跨级、本人、非直属成员、匿名请求拒绝且响应不泄漏目标邮箱。
- 覆盖连续重置仅最新凭据有效、同请求 ID 重放 409、同一目标并发重置仅一个凭据有效、旧密码立即无效、登录强制改密、改密后会话撤销。停用成员重置后保持停用，新临时密码仍不能登录。
- 重置前后账号数量、目标邮箱/角色/组织/姓名/状态及 `procurement_ledger` 记录数相同；未触发外部适配器或付费调用。失败请求后跨企业目标账号密码摘要及业务字段逐项相同。
