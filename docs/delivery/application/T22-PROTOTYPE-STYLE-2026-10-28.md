# T22 邮件页面原型风格调整

日期：2026-10-28。范围为邮件发送记录页与档案写信组件。参照 `原型设计/原型V2.html` 的蓝紫强调色、浅色画布、白色卡片、细分隔线与窄屏单列布局；沿用当前控制台外壳。平台邮件日额度页已有相同视觉基线，本次未改动。

## 改动与契约

- 发送记录由纯文本长列表调整为批次卡片、结果摘要和逐收件人详情。待确认、暂停、失败、送达状态使用不同标签色；原状态文字、按钮、显示条件、RouterLink 目标和事件处理保持不变。
- 档案写信的联系人选择、模板编辑、预览和发送确认增加卡片、分隔、表单与窄屏样式。没有修改组件脚本、请求适配或提交条件。
- 工作区中的 `web/styles/index.ts` 等共享文件有其他会话的并行改动，本次未改写。新增样式均留在对应模块组件内。
- 选择至提交参数与来源保持现行链路：预览的内部档案 UUID、内部联系人 UUID、所选企业/个人邮箱和 `mailsouId` 仍由原脚本进入 `email-drafts`，用户选择的 `channelId`、两项确认进入 `email-batches/confirm`；发送记录详情仍以路由 `batchId` 请求。测试夹具中的列表标识 `list-111`、详情标识 `detail-222`、源 `id/fileId` 与内部 UUID、`mailsouId` 均不相同。
