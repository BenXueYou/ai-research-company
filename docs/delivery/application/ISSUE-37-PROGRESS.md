# #37 平台直属下级迁移：基线，尚未交付

现有 `web/pages/organizations/OrganizationOpening.vue` 同时承载开户、直属列表、详情展开、凭据交付、重置及停用恢复；平台与分销共用该组件，由 `CompatWorkspace` 挂载。当前平台 `/platform/organizations` 仍是兼容容器定位，列表、开户和详情尚不是独立可定位页面。

迁移前的参数来源：开户提交 `name`、`kind`、`countryCode`、`phone`、`email` 及页面内 `requestId`；上级由服务端会话确定。默认类型为 `terminal`，区号为 `+86`，可选类型来自列表响应。停用恢复提交所选列表项的 `child.id` 作为 `organizationId`，重置提交同一项的 `child.accountId` 作为 `accountId`，并生成重置请求标识。凭据只在当前内存显示；关闭开户凭据时清空输入并生成下一次开户请求标识。开户失败后现有组件保留相同请求标识以供重试。重置当前每次点击生成新的请求标识；对结果不确定时的防重复行为需单独核对，不得在迁移时假定具有跨页面持久化。

本次复跑 #35 浏览器场景时，使用不同的组织、管理员账号和父组织 ID 核对开户及状态请求；该回归不等于 #37 验收。仍需实现和验证独立列表、开户、详情及关联入口，覆盖离开确认、一次性凭据、跨级拒绝、停用恢复、余额和在途状态，以及丢失响应后的请求与落库行为。未修改 #37 业务代码、部署或修改工单。
