# 找企业顶部引导优化（2026-10-29）

## 实现

依据本轮用户批准的设计，将产品空态中现有 SVG 地球插画移入 TerminalSearchPage 顶部统一引导横幅，标题为“找到目标企业，发现合作机会”。两个既有锚点入口归入横幅，仍直接定位公司名和产品词查询区域，不卸载组件。查询卡片统一标题，移除重复眉题和产品表单下的空态横幅，更新产品操作说明。桌面横幅与卡片同宽，窄屏隐藏插画、入口可换行。无新增依赖。

仅调整模板与样式，以及现有测试中的产品标题定位；两个业务组件 script、API、服务端均未修改。保留工作区开始时已有的组织详情与 package-lock 等其他改动。
