## 精确阻塞条件

1. 供应商正式账号、书面联调授权及两家企业各自独立的供应商资源标识；需供应商证据证明资源、任务、模板和地址池不能跨企业访问或复用。
2. 两家企业获授权的发信域名、发信地址、真实可收信的回复地址，供应商要求的 DNS 记录及验证状态；避免对现有生产域名盲目修改。
3. 获准接收小批量测试邮件的收件人名单与发送窗口、回复操作人，以及拒投/退信测试地址；须有权限查看收件箱和回复邮箱的实际结果。
4. 任务 API 的小批量路径、地址池与模板创建/绑定规则、变量映射、`tpl_id` 对本次编辑内容的优先级、`relpy_to` 生效方式、附件格式/大小、频控/恢复、逐收件人回执和证据 ID 的正式接口资料与额度。未知规则不得自行补值。
5. 按供应商真实响应实现并接入资源/域名核验、发送及证据核对适配器，在独立环境中先验证归属和状态映射。密钥通过受控配置提供，只记录配置项和脱敏结果。
