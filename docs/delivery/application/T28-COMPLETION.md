# T28 终端用量、分销交易利润与平台全链查看

实施时间：2026-10-27。本票仅新增只读报表、平台/分销自有账务 CSV 和页面入口；未改查询、订单、邮件或组织状态转移事务。

## 实现

- `server/reporting.ts`：服务端从身份所属组织推导组织树，不接收客户端组织标识。终端只返回本组织账户及详情、联系人、产品查询只增流水；分销返回下级组织状态、账户、汇总用量和邮件额度、自有交易及历史毛利；平台增加全链交易、客户、邮件、采购账务和库存。
- 平台销售毛利取平台作为卖方的 `point_transfers.gross_profit` 快照；平台承担费用仅汇总 `platform_expenses` 主记录，已关联的补充值不再增加该项；“扣除平台承担费用后”单列，不称净利润。
- CSV 仅输出平台或分销自身的账务字段和自身销售快照，不包含下级客户、邮件正文或腾道查询条件及原始数据。终端导出返回 403。
- 页面显示组织的 `active` 状态数据保留在报表响应中，T26 停用规则由原组织状态服务负责。

## 已验收

- 独立 PostgreSQL 测试库、3188 端口真实 HTTP：四个不同组织及账号（平台、分销、直属终端、旁支终端）；终端只见自身余额、冻结和查询结算流水；分销只见授权树，旁支及客户关键词不出现在响应或 CSV；平台能看全链交易，卖方/买方标识分别核对。
- 交易毛利快照：平台自身销售 1.5000、分销自身销售 1.0000；失败费用 0.5000、超额费用 0.2500；关联后续充值 0.5000 后费用仍为 0.7500，扣除后为 0.7500；重复来源费用被数据库唯一约束拒绝。
- Chromium 浏览器：终端页面只显示用量；分销显示交易毛利和自有导出；平台显示三项分列金额及旁支组织停用状态。
- `vue-tsc --noEmit`、`tsc -p tsconfig.server.json --noEmit`、`vite build --outDir .scratch/t28-web`、`node --env-file-if-exists=.env.test node_modules/tsx/dist/cli.mjs --tsconfig tsconfig.server.json --test server/reporting.test.ts` 均通过。浏览器构建输出隔离在 `.scratch/t28-web`。
