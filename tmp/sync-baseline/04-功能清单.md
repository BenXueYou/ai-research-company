1. **每个功能都有唯一编号**（如 `T-11`、`F-05`、`C-12`），调整时直接引用编号即可，例如：

## 二、模块 1 · 基础设施与腾道适配层（F-01~F-15）

> **PRD 未编号但必须建设**。技术设计文档 §2 明确指出这是本项目技术风险最高的部分：腾道存在大量「HTTP 200 + `success=true` 但数据错误或为空」的静默失败陷阱，必须集中在防腐层用代码强制拦截。**严禁业务代码直接拼腾道请求。**
>
> 这一组不产生用户可见功能，但决定其余 100+ 项功能是否可靠。裁减此组 = 后续必然返工。

| 编号 | 功能 | 说明与验收要点 | 优先级 | 建议纳入 |
|---|---|---|---|---|
| F-01 | 项目脚手架与 CI/CD | 多实例部署基线；PG / Redis / ES / 对象存储环境搭建 | P0 | MVP |
| F-02 | 统一响应解析层 | 业务成败只看 `success` 不看 HTTP 状态码；`code` 按**字符串**解析并兼容数字；读 `data` 前判空；分支判断只用 `code` 不用 `msg`；每次调用记录 `traceId` | P0 | MVP |
| F-03 | 翻页守卫 | **请求前**校验 `pageNo×pageSize ≤ 10,000` 且 `pageNo ≤ 1,000`；越界引导用户拆分条件。越界时返回 0 条、`total` 归零、`code` 仍为 `"200"`，**无法与「真的没数据」区分，故绝不能依赖响应判断** | P0 | MVP |
| F-04 | 参数构造规范 | 分隔符分派：`country`（数据源）用**逗号**、`hsCode`/国家码等业务字段用**分号**、联系人 `positionTag` 用**逗号**——用错返回 0 条且不报错；国家码强制 ISO Alpha-3；区间参数强制两元素且两端有值；**请求 DTO 与响应 DTO 完全分离**（请求 `sumOfUSD` / 响应 `sumOfUsd`） | P0 | MVP |
| F-05 | `conditionGroups` 高级入参构造与校验 | 组 ≤5、单组 ≤10、合计 ≤25 请求前校验；每组至少含一个 `CONTAINS`；区间条件须写在条件组内部；确认多组之间为「或」 | P1 | V1.0 |
| F-06 | 配额与限流守卫 | 全局令牌桶 ≤200 次/分钟；日请求数计数 ≤30,000；接近上限自动降速并告警 | P0 | MVP |
| F-07 | 计费与点数记账引擎 | 预估 → 用户确认 → 扣点流水对账（游标分页 `hasMore`/`nextCursor`）；**请求幂等去重防重复扣点**；预估与实际偏差监控 | P0 | MVP |
| F-08 | 「返回 0 条」诊断链 | 适配层内置排查顺序（技术设计文档 §2.9），把静默失败转成可解释的用户提示 | P0 | MVP |
| F-09 | 各接口独立 Response DTO | 10+ 接口的列表字段与分页字段**互不统一**：`data.content` vs `data.list`；`page/size` vs `pageNo/pageSize`；游标式 vs 页码式；`importers-stat`/`exporters-stat` 无数组（`data` 本身即单聚合对象）；`/v2/company` 单对象；`/v2/contact/{id}/social` 直接是数组。**禁止写「先试 content 再试 list」的统一兜底** | P0 | MVP |
| F-10 | 数据模型与建表 | ER 设计（技术设计文档 §3.2）；JSONB 容纳腾道数据源专有字段；业务主键去重 | P0 | MVP |
| F-11 | 落库去重与批量任务断点续跑框架 | 以腾道记录 ID / `mailsouId` 为业务主键；批量任务支持断点续跑 | P0 | MVP |
| F-12 | 字段填充率验证工具 | **上线前必做**：针对目标国家地区、数据源与关键字段验证实际填充率，避免功能做完但数据是空的 | P0 | MVP |
| F-13 | 可观测性 | 全链路 `traceId`；外部调用记录接口路径、耗时、HTTP 状态、**脱敏后**参数与错误信息；指标与告警 | P0 | MVP |
| F-14 | 安全与合规基线 | apiKey / accessToken / 邮箱授权码经密钥管理服务存储，**严禁硬编码或进代码仓库**；个人数据加密；审计日志框架 | P0 | MVP |
| F-15 | 容错与降级 | 腾道接口异常时降级为本地缓存数据，并**明确标注数据时效** | P0 | MVP |
