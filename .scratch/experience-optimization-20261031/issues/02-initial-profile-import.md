# 02 — 当前页名单显式入库为初始企业档案

**What to build:** 用户在公司名或已取得的产品词名单中默认选中当前页，剔除后显式保存，立即在企业档案库和同一详情页看到待核实初始档案。

**Blocked by:** 01 — 建立可演练的版本化升级与数据保全入口。

**Status:** completed-local

**基线：** 需求基线：《产品需求文档PRD》v3.3、《第一阶段实施规格Spec》v1.4、《技术设计文档》v3.5及《体验优化技术设计与实施依赖》v1.1；遵守仓库现行约定与已批准身份决策。以当前代码和交付证据核对已有能力，保留其他任务未提交修改。

**验收追溯：** AT-08、AT-25、AT-26。

**证据与完成边界：** 已有本地名单及受控搜索结果即可验收；不依赖正式供应商调用。

- [x] 当前页默认全选不产生入库；切换搜索条件隔离选择，用户提交仅保存提交时已取得且选中的来源。
- [x] 初始档案允许无详情、无详情查询和未知企业国家；产品词的筛选国家不冒充返回国家，身份待核实明确显示。
- [x] 保存来源原文、查询条件及页码；相同来源并发及相同请求重复提交返回同一档案，不重复创建。
- [x] 入库零次上游调用、零冻结、零扣点；未取得的页和之后迟到的名单不会自动入库。
- [x] 列表、同一详情页及既有人工维护支持初始档案；旧档案、附件、时间线及邮件读取正常。
- [x] 跨企业来源、停用账号/组织拒绝；附增量升级、HTTP及真实浏览器验证，标识字段取不同值。

**前端交互与页面风格验收：** 沿用当前实际业务页面的导航、页签、列表与详情关系、表单编排、按钮层级及位置习惯、确认与反馈方式、加载/禁用/空态/错误提示、返回与离开保护及响应式布局。新增选择、批量操作、进度及失败项复用现有页面结构和组件模式；不另建任务中心、重排导航或进行视觉改版。沿用 Element Plus 默认控件外观、统一主色 #4356e0 和公共表单布局，保留键盘操作、焦点及原有状态留存约定。仅按已确认需求调整默认选择、显式入库、批次一次确认、独立联系人和费用等待不锁其他操作等行为；逐票列明必要变化，不扩大到其他交互。实施前记录受影响实际页面的基线，交付在宽屏、中间宽度和手机宽度核对前后布局及交互，明确隔离预览与完整业务页面验收的区别。

**交付要求：** 记录实际修改、受影响流程、实际执行命令和结果、尚未验证项。涉及选择至提交的链路，提供标识取不同值的夹具、最终请求值及来源、允许/拒绝结果、调用次数和适用账务证据。静态检查与构建不能替代本票业务验收。
