## 拆分原则

01为必要前置整理，其余实施票按具体业务闭环切分，包含所需数据结构、服务端、页面及验收；14/15/17为真实供应商能力与联调闭环。各业务票携带自己的增量迁移，不把未来全部数据结构塞入01。16验证集成影响和同步配套材料，不替代每票独立验收。

技术设计W0～W7是工作包，本表将其拆为单会话任务；依赖以本表的具体交付为准。06不依赖05，12不依赖09，11不依赖08，避免把详情/批量交付误当独立联系人或单项结算的前置。

02～13中的受控验收可先做；正式分支按各票门槛保持受限，不能以受控通过冒称真实供应商验收。14、15、17须证据及明确联调授权齐全后完成；其中14真实搜索取得结果不代表真实自动计费已通过。
