## 所有功能票共同完成标准

- 固定技术栈：Vue 3 + TypeScript + Vite + Element Plus前端，NestJS + TypeScript后端，PostgreSQL持久化；Redis及私有对象存储随首次相关能力落地。全新建设，不承担本地试验代码、旧表结构或历史接口兼容。
- T01承担基础单环境部署脚本、配置说明、新库初始化及初始账号引导验收；后续首次引入运行设施的票同步扩展部署入口与说明。T21承担公共模板最小受控预配工具、版本及附件引用验证和操作说明；模板附件权限和限制已确认，渠道兼容仍须验证。

- 票内贯穿用户入口、真实应用服务、持久化及系统级场景。首次引入能力的票同时落地其最小运行设施；不单列前端、后端、数据库、测试等横向工单。仓库当前原型不是生产实现，也没有必须先做的生产代码重构。
- 以 UI 驱动真实服务端及测试数据库；越权、并发、乱序和重复操作可补充公开应用接口场景。供应商仅在外部适配器边界替换为可控响应，不替换本地鉴权、数据库事务或账务。
- 最早引入相关能力的票就必须实现拒绝路径、幂等和安全状态：查询不确定先保留冻结；邮件不确定先保留原日预占且不自动重发；跨日未执行先暂停；不能等后续专项票才防止错误扣点或发信。
